逐条明细

统计范围与归属

玩家栏合并已识别的游戏连接及关联到同一浏览器的 HTTP 下载。识别前或无法关联的请求保留在“未识别”，不会按 IP 猜成某个人。房间代码复用时使用独立记录编号区分。

SakuraFRP 栏记录官方账户今日用量、剩余流量、每次观测的用量变化及补充/重置。账户所有通道共享，无法准确把账户账单分摊到个人。FRP来源确认只代表本机进程与连接匹配；Tailscale地址仅标为候选，其他本机转发保留未分类。

游戏明细约每30秒落盘，监视台导入后长期保存在 data 文件夹。游戏服另存于 runtime/monitor-traffic。关服后可继续查询已导入的历史。更早的未安装新版 boot 的流量无法补记。
