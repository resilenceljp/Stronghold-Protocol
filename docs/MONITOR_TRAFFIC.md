# 服主流量账本 · UI 1.9 / boot v8

入口：监视台左侧「流量账本与历史」。游戏服与监视台均更新、重启后开始记录。安装前未记录的历史不能补算。

## 记录内容

| 分类 | 内容 |
|---|---|
| 局内 | 确认信息、策略/机变、休整、战斗、联防、Boss及无尽投票期间的收发 |
| 局外 | 大厅、房间等待、开始前预缓存、未识别请求 |
| 房间/每局 | 独立房间编号、房间代码、局数、回合、阶段、模式和难度 |
| 玩家 | 已识别WebSocket身份；同一浏览器的HTTP关联；无法关联的单列未识别 |
| 传输类型 | 游戏消息、图像/头像、模型/动作、声音、游戏数据、脚本/样式/字体、页面/其他 |
| 字节 | 服务器接收=玩家上传，服务器发出=玩家下载；两者分别显示与合计 |
| 房间历史 | 创建、每局开始/结束、关闭；胜负、玩家LP、资金、伤害、击杀等最终数值 |
| SakuraFRP账户 | 官方今日已用、剩余、观测区间用量变化、剩余净变化、补充及日切/重置 |

游戏字节读取真实TCP socket的 `bytesRead/bytesWritten`，包括压缩后的内容与HTTP/WS框架；不含TCP/IP头、TLS、FRP封装、重传等网络/平台额外开销。监视台的本机探测与图片代理请求用专用标记排除，管理端口也不属于游戏端口计数。

房间与阶段归属在消息/请求边界及每秒采样；跨边界的异步压缩、写出可能有少量归属偏差。它是可审计的游戏使用统计，**不是SakuraFRP平台账单**。

## 玩家归属

WebSocket使用服务器已经验证的玩家身份。浏览器在建连接前写入随机的非敏感 `sp_monitor_client` 编号，HTTP请求通过这个编号与已识别游戏连接关联；它不是登录凭据、重连令牌或管理权限。浏览器禁止Cookie时仍可玩，只是部分HTTP流量无法归属。

不会按IP猜成某个玩家：FRP、同一网络或共享代理可能让很多人拥有同一个来源地址。完全无法关联的流量保留在「未识别请求」，仍计入局外/总量。AI不拥有独立客户端，AI模拟本身是CPU开销；给真人发送的AI战况计入收到数据的真人连接。

连接来源分为本机FRP进程与端口确认、Tailscale地址候选、本机/转发未分类、直连/其他。短HTTP连接未被进程采样捕获时保留未分类，不假称已确认走FRP。

## 持久化与查询

- 游戏服：`runtime/monitor-traffic/traffic-YYYY-MM-DD.ndjson` 与 `rooms-YYYY-MM-DD.ndjson`，每30秒或对局结束落盘。
- 监视台：`monitor/data/traffic-YYYY-MM-DD.ndjson`、`rooms-YYYY-MM-DD.ndjson`、`sakura-YYYY-MM-DD.ndjson`；独立版在程序旁 `data/`。
- `traffic-cursors.json` 保存按字节的导入游标；重启后继续，不把已经导入的字节再次累计。
- `traffic-source.json` 保存已识别的本机账本位置。游戏关闭后仍可读取它，镜像末尾数据并查询历史。
- `sakura-last-observation.json` 保存下一次账户变化比较基线，仅含选定用量字段，不含账户令牌或原始API响应。
- 日期以UTC+8划分。UI提供当天汇总、逐条明细、分页和NDJSON下载；日志不会自动删除，空间随使用增长。

实时启动总量与已落盘每日汇总是两个范围，后者可能滞后约30–60秒。内存明细最多5000分类单元，界面实时快照最多500条；更早的完整明细保留在磁盘。房间代码重新使用时，新编号避免混合两间房。

SakuraFRP账户流量包含账户的全部隧道。可用量增加可能来自补充/刷新；跨日、计数重置和换账户时不臆造区间用量。不能准确将账户花销分摊到某间房或某个人。

## 更新与接口

boot v8依赖同目录 `monitor-v6.js` 和 `traffic-ledger.js`。安装器备份三个已有文件，复制新版；游戏下次启动生效。UI需要独立重启，不影响游戏对局。

本机管理员 `GET /admin/traffic-history?day=YYYY-MM-DD&kind=usage|rooms&cursor=字节偏移&limit=200`；UI代理 `/api/traffic-history`、`/api/traffic-report`、`/api/traffic-export`。仅允许固定日志种类与日期，不接受任意文件路径。游戏管理接口只绑定127.0.0.1。

发布ZIP排除 `data/`，源码与便携更新排除 `runtime/`。私人设置、账户凭据、房间/聊天/流量历史不会进入仓库或分发包。
