# 娱乐扩展 fun.3：布局与手机素材

当前版本：0.2.5-20p-fun.4，基线 LongQianChen20p 0.2.4。

## 手机 / iPad

在标题页或大厅「设置」开启「手机精简画面」，会同时静音；重新进入对局后生效。使用头像代替模型，保留名称、棋子详情、站位、商店、操作与正常战斗计算。关闭精简后可自行恢复音量。完整模型模式不属于精简包保证范围。

素材包不需要在手机上解压：HTTPS 或 localhost 下进入大厅「预缓存」→「导入本地素材包」→选择 ZIP。普通 HTTP/IP 下浏览器可能不支持完整缓存能力，仍可正常按需加载。浏览器清理数据、更换浏览器或网址来源会影响缓存复用；不要在对局中清理浏览器数据。精简包保留完整校验目录但只有部分资源，不能开启要求完整预缓存的准入限制，也不要点击在线补齐全部缺项，否则会重新下载完整资源。

本次在本地 diy 安装测得：完整素材618.10 MiB，完整ZIP481.99 MiB；精简素材94.64 MiB，精简ZIP95.69 MiB。大小随源素材更新变化。原始磁盘额外文件不全属于有效目录。

服主制作命令：

```powershell
node tools/asset-cache-pack.mjs --lite --out D:\Stronghold-Protocol\素材包
node tools/asset-cache-pack.mjs --out D:\Stronghold-Protocol\素材包
```

精简包保留头像、道具与主要界面图片，不含音频、Spine模型、半身立绘、说明大图、加载和结算大图。精简模式部分说明页仍可按需下载图片，并非严格离线客户端。

## 娱乐 / 无尽布局和规则

- 模式按钮与难度标题并排；无尽使用紫色说明卡，敌人仍按每回合10%增长。
- 第二页同时显示关闭/开启、官方/满练度、8/12部署位；高亮所选项。
- 首页面显示必须先确认第二页才可准备的提示。
- 使用原版「重刷本局」：全体真人同意后重新随机战场、领袖、特训与禁用；保留房间、个人配置和娱乐设置。不是只换战场。
- 藏品池改为紧凑列表；已获藏品显示在右侧长期效果栏，点击查看单件说明。
- 控制台置于左下；临时整备区在普通整备区下方靠左，普通区空位立即自动吸收临时棋子。
- 无尽调度7级比6级多一个干员槽和一个普通装备槽，取消特殊道具抽取规则；价格、其他经济与成长规则不变。
- 满练度现有数据边界沿用fun.2：未新增完整技能专三/模组三级数据表。
